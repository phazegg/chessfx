# ChessFX website

A static landing page (no framework, no build step to host). The hero board runs the extension's real shaders and
piece sets and plays Morphy's Opera Game; visitors switch looks, compare with the original board, and browse all
animated boards.

- `index.html`, `site.css`, `site.js`: the page.
- `privacy.html`, `terms.html`: generated from the extension's `account/` pages (fill in their placeholders there).
- `assets/`: generated by `node tools/build-site.mjs` (shaders, board stills, piece PNGs, looks, the demo game,
  tokens). Rebuild after changing looks, shaders or piece sets; don't edit `assets/` by hand.

## Before going live

1. **Store links**: in `site.js`, set `STORE.chrome` (and `STORE.edge` if listed) to the store pages. Until then the
   buttons scroll to the closing section, which says ChessFX is launching soon.
2. **Domain**: replace `https://chessfx.app/` in the canonical link of `index.html` with the real domain.
3. **Legal pages**: fill in the contact email and country in `account/privacy.html` and `account/terms.html`, then
   rebuild.
4. Optional: once the listing is live, Google's "Available in the Chrome Web Store" badge may be added as a secondary
   element (it must link to the listing and must not be the page's main element).

## Hosting

Any static host: Cloudflare Pages, Netlify or GitHub Pages. Publish the `site/` folder as the site root.

## Principles (from the council)

- The product itself, live, above the fold; a still poster paints first and the shader starts when the page is idle.
- Reduced motion: the board starts paused (a play button starts it); the preview always has a pause control.
- Honest only: no fake reviews, counters or rankings; "cosmetic only" and "not affiliated with Chess.com" stated.
